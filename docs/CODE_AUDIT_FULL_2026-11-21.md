## 2د. الجولة الرابعة — المجموعتان 2 و4 (خمسة وكلاء)

- **المتجر:** تسعير موحّد عبر `resolve_store_price`، سعر صرف معكوس متطابق، لا مضاعفة FX،
  مرجع البوابة مُلتزم، وقفل تكرار دائم `(tenant, sale)`.
- **الويب هوكس:** dedup لكل حدث، fail-closed عند غياب Redis، العلامة بعد النجاح فقط،
  IPN بتوقيع HMAC-SHA512 على الجسم الخام والتحقق قبل القفل، وتوحيد بوابة الفوترة مع نفس الخلفية.
- **الجدولة/الخيوط:** موافقة تلقائية مسجّلة في `create_app()` (WSGI)، منع التكرار،
  خيوط التنظيف/التليمتري مرة واحدة لكل عملية.
- **API/SSE:** `/api/search` pagination صحيحة، لا غلاف `success:true` لنتائج فاشلة،
  SSE بقفل ونبضة حياة واشتراك KDS عبر العمال، وتحقق `Warehouse.tenant_id` غير مشروط.
- **المخطط:** 16 FK مركّباً إضافياً (المجموع 33) + توثيق الـ downgrades أحادية الاتجاه
  + توحيد اسم قيد `sync_batches` + إزالة cascade من أطفال الصيانة.
- **البنية:** تبديل آمن واحد من `models→services` إلى `utils`، وتعليقات allowlist لبقية
  الواردات الضرورية (GL posting، workers، restore) حتى لا تُعامل كأخطاء مستقبلاً.

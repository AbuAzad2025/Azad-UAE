# دليل الصفحات والصلاحيات — Page & Access Matrix

تولّد هذا التقرير تلقائياً من خريطة المسارات الحية مع اختبار دخول فعلي لكل نوع مستخدم.

## أنواع المستخدمين

- **owner** — مالك المنصة
- **manager** — مدير الشركة
- **accountant** — المحاسب
- **seller** — البائع
- **cashier** — الكاشير
- **inventory** — أمين المخزون

## مفتاح الحالة

- `200` — الصفحة متاحة؛ `302` — تحويل (مثلاً إلى لوحة التحكم)؛ `403` — مرفوض؛ `404` — غير موجود/مخفي؛ `500` — خطأ خادم (يجب أن لا يظهر).
